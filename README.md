# Clash 应用代理配置助手 1.1.2

界面按内容高度自动排版，支持 Windows DPI 缩放；小窗口通过垂直滚动查看完整内容，避免文字、按钮和恢复链接被固定行高遮挡。

Windows 10/11 x64 独立 EXE。需要已安装并启动初始化过的 Clash Verge Rev；本工具使用它的 Mihomo 内核，不内置 Clash 客户端。依赖 Windows .NET Framework 4.7 或更高版本。验证环境：Clash Verge Rev 2.5.2 / Mihomo v1.19.29。

## 使用

1. 双击 `ClashConfigAssistant.exe`。首次打开代理地址为空；保存过记忆后自动填回。每次打开应用均不预选，可点“恢复上次应用选择”。
2. 选择 Clash 订阅、HTTP 或 SOCKS5，填写地址。普通代理支持主机:端口或对应协议 URL，账号密码可以单独填写。
3. 启动时自动列出正在运行、有窗口且可读取路径的软件，默认不勾选。勾选应用；之后启动的软件可点“刷新运行软件”加入，没有列出的组件用“添加 EXE”加入。必须包含该应用所有实际联网组件。
4. 点击“仅检查代理”可先验证出口。点击“一键应用＋断网保护”，按 Windows 提示授予管理员权限。应用会短暂断网，配置成功前不会报告完成。
5. 打开目标软件并产生实际网络请求，再点“验证当前连接”并授予管理员权限，以检查系统保护状态。没有捕获到该软件连接时，不能判定它已经经过代理。

## 本机记忆

“记住当前填写”保存代理类型、地址、账号密码、开机选项和已选应用路径；成功应用后也会自动保存。记忆使用 Windows DPAPI 当前用户加密，存于 `%LOCALAPPDATA%\ClashConfigAssistant\preferences.bin`。重新打开只填回表单，不自动切换网络。应用选择须手动勾选或点击恢复；消失的 EXE 路径不会恢复。

“清除记忆”删除这份加密表单记录并清空当前表单，不撤销已生效的 Clash 配置，也不删除配置备份。需要撤销代理时使用“还原上次配置”。不要向别人分享整个本机数据目录。

“Clash 随 Windows 登录启动并保持此模式”默认开启。设置生效后可以关闭配置助手，Clash 继续运行。不要同时启用其他代理客户端。

## 代理格式

- 订阅必须是 HTTPS 链接，响应是包含内联 `proxies` 的 Clash YAML。不支持仅含 proxy-providers 的订阅或 Base64 节点列表。
- 订阅导入为本地快照，重新填写并应用才会更新。初始使用第一条节点，可在 Clash 的 `Selected-Apps-Proxy` 组切换节点。
- HTTP 代理不能承载普通 UDP；此类流量应被拒绝。需要 UDP 的应用应使用支持 UDP 的上游节点。
- 检查出口会经代理访问 api.ipify.org 或 myip.ipip.net。代理不可用时不应用配置。

## 严格保护的实际范围

所选 EXE 的公网连接按路径匹配代理，代理组没有直连回退。Windows Filtering Platform 规则限制这些 EXE 通过指定 TUN 接口联网；接口不符合时阻断。IPv4、IPv6 均安装规则。回环和私有局域网保留直连，以兼容手机连接等本地通信。

这不是对任意应用“所有流量永远不泄漏”的保证：未加入的辅助 EXE、通过共享系统服务或其他本地程序代发的请求，不属于已选 EXE 的保护范围。程序更新改变 EXE 路径后必须重新添加并应用。TUN 接口身份改变时会阻断，需重新应用。无法识别进程的流量默认拒绝，可能影响某些未选择的程序；识别到的其他程序按直连规则处理。

Windows“手机连接”的进程代理不等于手机本身的应用流量经过代理。本工具不配置手机网关。代理也不能保证账号不被限制。

## 还原与故障恢复

优先用“还原上次配置”，恢复本工具改动前的配置及对应保护状态。每次应用都会备份。

如需紧急解除阻断，点击“故障恢复：只解除本工具的系统断网保护”。它仅删除本工具的保护规则，不还原 Clash 配置；解除后程序可能直连。不要在保护仍启用时直接删除 EXE，否则将失去便捷的还原入口。

备份位于 `%LOCALAPPDATA%\ClashConfigAssistant\backups`，包含原配置，可能含代理凭据。导入的代理保存在当前用户的 Clash 配置目录。请勿把这些目录分享给别人。发布 EXE 和源码包没有预填订阅或用户凭据。EXE 未进行商业代码签名。
